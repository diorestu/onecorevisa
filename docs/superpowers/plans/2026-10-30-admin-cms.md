# Admin CMS Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task.

**Goal:** Deliver a Tabler Free admin panel connected to EN/ID public content.
**Architecture:** Laravel Blade and Eloquent, with a legacy-content provider for idempotent initialization and pre-import fallback. Explicit administrator authorization protects the entire admin route group.
**Tech Stack:** Laravel 12, PHP, SQLite/MySQL, Tabler Free, local JavaScript and CSS.
**Spec:** `docs/superpowers/specs/2026-10-30-admin-cms-design.md`

## Global Constraints
- English and Indonesian only in content editors.
- Keep service URL mappings, redirects, existing price options and C13/C14 wording.
- No raw JSON editor, fabricated articles, public registration or default credentials.
- Validate uploads and sanitize rich text server-side; preserve existing edits on reimport.

## Review Focus
- Pre-import public requests must work without CMS tables.
- Imports after editing must preserve administrator changes and deletion decisions.
- Draft/inactive categories and future articles must not leak through public routes or discovery.
- Optional service fields and price variants must render safely on visa and legal pages.
- Translated labels must not cause per-string database queries or stale cross-request content.
